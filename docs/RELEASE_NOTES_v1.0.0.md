# The Lion King Windows Fix 1.0.0

This is the first public release for the Windows conversion of *Disney's The
Lion King* included in the European *Disney's Classic Video Games* collection
(1997).

It includes:

- a verified, reversible patch for the supported `LIONW.EXE`;
- GameVaultDraw for correct 8-bit DirectDraw presentation on modern Windows;
- borderless 4:3 fullscreen at a stable 60 FPS;
- working music, sound, taskbar, Alt+Tab and DWM preview;
- safe Keyboard and Joystick Properties pages;
- `F2` for Properties and `Esc` for a normal English exit dialog;
- a hidden gameplay cursor that returns automatically for dialogs;
- a console-free launcher that prevents long-path MIDI corruption.

Copy the contents of the release `patch` folder beside your own supported
`LIONW.EXE`, run `Install patch.cmd` once, and use `Play Lion King.exe`.

No copyrighted game files are included.
